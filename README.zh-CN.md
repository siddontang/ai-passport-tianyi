# AI Passport — 天依像素版

用于 **FoloToy AI Passport（ESP32-C3、8 MB Flash、无 PSRAM）** 的定制固件，
包含天依风格的像素头像、连续语音对话和中文字幕。
当前源码版本为 **2.2.1-tianyi.pixel.21**，已通过构建和主机测试，
电量显示、配网、设置及继承的重连改动尚待实机验证。

## 已实现

- 64×64 像素头像、眨眼、聆听反馈与音量驱动的嘴部动画，复用 240×4 DMA 条带渲染。
  pixel.21 使用确认后的头顶双发环、耳侧回弯发束及蝴蝶结造型。
- 上游 C3 Opus 音频实现、共享编解码工作区和增量 TLS 收发。
- 定时发送 WebSocket Pong，修复长语音回复期间服务端心跳超时导致的断开。
- 用户字幕即时显示；回复字幕按实际释放的 PCM 样本推进，考虑播放队列和 I2S 尾音。
- 中文字体、头像与字体生成工具、主机回归测试。
- 中英文界面、配网和激活引导、识别码倒计时；中文界面复用现有字幕字体。
- 语言选择重启保存；更换 Wi-Fi 经过确认，只清除网络配置，未联网也能进入设置。
- 天依主界面、菜单及配网页面显示电池图标和百分比，20% 及以下变色；每 5 秒采样。
  电量变化仅刷新顶部区域，不重绘头像和字幕。
- 修复界面在自动重连期间主动取消通话的问题；增加分页和服务端事件诊断日志。

字幕是近似同步：当前协议没有逐字时间戳。字幕窗口容纳 1,024 个 UTF-16 单元，
累积更新会回收已显示的前缀；一次到达的超长文本仍可能超出窗口。
嘴部动画跟随音量，不是逐音素口型。

电量计沿用设备已有的电芯校准；读取失败、未校准或尚未就绪时显示 `--%`，
不会把异常值显示成 0% 或 100%。已配置但休眠的电量计会在启动时唤醒。
本次不写入新的电芯参数，也不推测充电状态；采样位于控制任务，避开音频和渲染任务。

## 构建与烧录

先安装并激活 **ESP-IDF 5.5.4**（实机验收使用的版本）、Python 及 ESP-IDF 构建依赖：

```sh
git clone https://github.com/siddontang/ai-passport-tianyi.git
cd ai-passport-tianyi
python firmware/tools/build_firmware.py ai-passport-wifi --jobs 2
```

使用 USB 数据线连接设备并开机，确认串口后，烧录分段镜像以保留现有 NVS 设置：

```sh
idf.py -C firmware -p PORT flash monitor
```

把 `PORT` 替换成这台设备的实际串口。不要执行整片擦除或使用其他板子的分区布局。
构建产物和设备备份不随源码发布。新设备通过屏幕显示的 `AIPassport-XXXX` 热点，
访问 `http://192.168.4.1` 配网，再到 [Deotaland 控制台](https://bot.deotaland.cn) 激活并绑定 Agent。

## 使用与 Agent 设置

- 短按 OK 开始或结束通话；上、下键调整音量。
- 长按 OK 打开菜单，选择 **新建对话**，旧对话仍然保留。
- 选择第三项 **更换无线网络**，再选择 **清除并重启**，即可重新配网；默认选中取消。
  设备身份、Agent 绑定、保存的会话和语言设置均保留。
- 选择第四项 **语言设置**，可切换中英文，默认中文，重启后保持。
  新打开的手机配网页面默认跟随设备语言，也可单独切换页面语言。
  语言设置只改变界面文案，不会改变 Agent 名字、语音或对话字幕内容。
- 在控制台的 Agent 人设里设置自称。修改人设后应新建对话，已有会话可能保留旧指令。
  实机新对话已确认使用自定义名字 **Tiantian**。

头像不会改变音色。目前**尚未实现洛天依风格音色**：实际音色由服务端供应商配置决定，
当前控制台没有独立的每 Agent 音色选择器。说话风格提示词不能代替音色预设。
此仓库不包含 Agent Stack 服务端代码。

## 验证记录

pixel.21 仅更新头像素材，保留 32 KB 素材大小和原有局部表情刷新方式。
生产渲染器测试覆盖四个表情、局部刷新、中文字幕及中英文电量更新；
语音、重连、电量采样和设置逻辑保持不变。

pixel.20 已通过 AI Passport WiFi 固件构建及实际电量驱动测试，覆盖唤醒与读取失败、
保留校准、0%／100%／无效读数和 5 秒采样间隔。双语渲染测试确认电量单独变化时
只传输顶部 8 个条带（15,360 字节），其他区域的像素保持不变。
头像、按键、字幕、重连及设置回归测试通过；电量读取与显示尚待实机验收。

pixel.19 已通过 AI Passport WiFi 固件构建、语言保存、实际菜单确认与取消、
Wi-Fi 存储隔离及写入失败测试。生产渲染器覆盖双语配网、激活码过期、离线菜单、
天依头像与字幕；真实配网页面处理函数覆盖双语和包含模板符号的网络名。
同时通过实际重连工作线程、界面通话管理、
麦克风循环的故障注入测试。覆盖两次退避重试、恢复采集、重试耗尽、授权失败、
用户主动结束和状态切换竞争；同时通过中文菜单渲染、UTF-8 边界、头像、字幕、
心跳、平台分页与编解码生命周期测试。本版尚未烧录或完成实机验收。

每次通话最多自动重试两次，分别等待 2 秒和 4 秒，再申请新的语音连接。
重连期间暂停采集，丢弃中断的音频；恢复后可继续说话。
服务端明确结束、授权失败或平台连接丢失仍会退出通话。
服务端明确标记 `recoverable: true` 的非致命错误会保留当前通话。

pixel.16 已通过 ESP-IDF 构建及头像、字幕、平台 API、编解码生命周期、心跳和恢复测试。
用户实测确认声音、连接与中文字幕跟随正常。记录中包含一段完整的 43.36 秒回复，
连接至少保持 100.46 秒；这代表有限时长的实机验收，不代表无限时长稳定性保证。

测试命令见 [英文说明](README.md#validation)。头像预览和素材生成需要 Pillow，
字体生成另需 fontTools；已提交生成后的 C/C++ 素材，正常构建不需要重新生成。
